# Interesting Core JavaScript Questions

A collection of core JavaScript concepts, patterns, and interview questions implemented through practical examples.

## Description

This repository contains hands-on implementations of fundamental JavaScript concepts, design patterns, and commonly asked interview questions. Each topic is organized in its own directory with working code examples.

## Structure

Each topic directory contains:
- `main.js` - The main implementation file
- Additional supporting files as needed

## Getting Started

1. Clone the repository
2. Navigate to any topic directory
3. Run the examples with Node.js:

```bash
node main.js
```

## Contributing

Feel free to add new topics or improve existing implementations. Each topic should:
- Be placed in a numbered directory (e.g., `3. topic-name/`)
- Include a `main.js` file with the implementation
- Follow JavaScript best practices
